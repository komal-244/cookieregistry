About the project

What is CookieRegistry?

CookieRegistry is an open community database for web cookies — inspired by Cookiepedia. Anyone can sign up and contribute cookies they've identified, building a shared global reference for privacy researchers, developers, and compliance teams.

How to contribute

Sign up with your name and email, then click "Submit a Cookie" to add entries you've discovered. Your name will be credited on each cookie you submit.

Cookie Categories

Advertising — Ad targeting, impressions, and campaign tracking.


Analytics — Usage patterns, performance, and conversion measurement.


Marketing — User identification and cross-site conversion tracking.


Security — Authentication, session management, and fraud prevention.


Functionality — User preferences and browser capability testing.
